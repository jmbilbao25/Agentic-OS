# Lessons

Activation-based: each line names the situation that should fire it. A lesson
without a trigger is a note. Wrong lessons get deleted, not archived.

- When starting any session in this repo → run `bash bin/os boot` before replying. Because the sandbox starts with no memory of the last session. _(2026-08-19)_
- When a session produces a decision, lesson, or finished step → `bin/os save` immediately. Because sandbox teardown discards uncommitted work silently. _(2026-08-19)_
- When work will outlive one context window → create a loop ledger instead of trusting the transcript. Because context compaction drops the middle of long sessions. _(2026-08-19)_
- When about to rely on a harness feature (hooks, custom agents, repo-level MCP, global config) → verify it actually loads in *this* surface first. Because unsupported config fails silently rather than erroring, and you will debug the wrong layer for an hour. _(2026-08-19)_
- When about to add a note that overlaps an existing one → rewrite the existing note instead. Because two notes disagreeing is worse than one note being stale. _(2026-08-19)_
- When `gh pr create` or any `gh pr`/`gh issue` subcommand is tempting → use `gh api` REST instead. Because the GraphQL-backed subcommands always fail in this sandbox. _(2026-08-19)_
- When the same loop step fails twice → stop, write the blocker into the ledger's Notes, escalate. Because a third identical attempt produces confident garbage. _(2026-08-19)_
- When verifying a generated UI → load it headless and assert on the DOM, don't assume it renders. Because a template typo produces a blank page that looks fine in source. _(2026-08-19)_
- When a session starts with an empty workspace or no repo bound → the brain is not missing, it is uncloned; run the sidecar clone from the global kernel before claiming no context exists. Because repo-resident config cannot load in a session bound to no repo. _(2026-08-19)_
- When the brain needs to be reachable from any session → keep it in its own repo on the default branch, cloned by the global kernel to a fixed path. Because hosted harnesses clone only the default branch and offer no branch picker. _(2026-08-19)_
- When the user wants an agent that is persistent like a real OS (daemon, scheduler, survives reboot) → that is a machine they control, not a hosted sandbox. Because hosted surfaces have no cron and tear the sandbox down per task. _(2026-08-19)_
- When asked to run one vendor's models through another vendor's agent CLI → say no and explain the boundary. Because agent CLIs authenticate only against their own subscription, their own API key, or a cloud reseller, and vendor terms forbid third parties exposing consumer logins. _(2026-08-19)_
- When writing the kernel → put it in a neutral file (`AGENTS.md`) and generate per-vendor bindings from it. Because a kernel written directly into one vendor's config path binds the OS to that vendor, which is the same mistake as binding it to one repo. _(2026-08-29)_
- When adding semantic search to a markdown vault → keep markdown authoritative and treat the index as disposable, rebuildable from source. Because state you cannot diff or review in a PR stops being memory and becomes a dependency. _(2026-08-29)_
- When sizing a box to host a vault plus a search index → a `t3.micro` is enough, provided inference stays remote. Because the index and a quantised embedding model are small; only the LLM is heavy, and it does not need to live with the data. _(2026-08-29)_
- When a note's own stated revisit-condition comes true → rewrite that note with the reconciliation, keeping the filename. Because the honest record of "we said X, then X's exit condition fired" is more valuable than either a stale note or a silent overwrite. _(2026-08-29)_
- When an integration seems to need a paid subscription → check whether the software and the inference are separately licensed. Because open-source agents are usually free while the model calls behind them are not, and conflating the two leads to paying for the wrong thing. _(2026-08-29)_
- When two symptoms share a call path → find the one shared function and fix it there. Because the AgentOS map drew nodes that 404'd and were unsearchable, and both were one load() vs load_all() split; patching the 404 alone would have left the search gap. _(2026-08-29)_
- When writing an auth check → run the expensive comparison unconditionally and combine the results after. Because short-circuiting on a wrong username made it 12x faster to reject than a wrong password, which is username enumeration in a timing side channel. _(2026-08-29)_
- When a hybrid ranker exists → test queries that are just a document's name, not only paraphrases. Because BM25 indexes the title identically on every chunk of a document so it cancels out, and the vectors never see the title at all, making name lookup the weakest query on the most common intent. _(2026-08-29)_
- When claiming a UI is done → open it in a real browser and assert on computed styles, not the source. Because a disabled button whose label was invisible, a highlight that never cleared, and tofu boxes from a subset font all read perfectly fine in the CSS. _(2026-08-29)_
- When a settings form is needed → generate it from a schema the server owns. Because a hand-written form and its validation drift apart within one change, and the schema can also carry the ranges, help text and reindex-required flags the UI has to show. _(2026-08-29)_
- When adding a secret-detection check → match credential signatures, never entropy. Because a loose pattern matched SESSION_SECRET = os.getenv(...) in ordinary code, and a check that cries wolf on normal source gets switched off within a week. _(2026-08-29)_
- When a pull request is merged → verify with 'git rev-list --count main..origin/<branch>' and a tree diff, not by trusting the merge. Because PR #1 merged at 1 commit while 9 more were still being pushed to the same branch, so main silently lacked 34 files while every push reported success. _(2026-08-29)_
- When reconciling two branches that both rewrote the same modules → pick one as the base and re-land the other's work as additions, porting only the genuinely shared files by hand. Because a three-way merge of two independent rewrites produces something that behaves like neither, while new files in untouched directories carry almost no risk. _(2026-08-29)_
- When porting code between branches → read the target's function signatures instead of assuming them. Because a file copy type-checks and still fails: the target's llm.stream() yielded event dicts where the caller expected strings, and llm.models() did not exist at all. _(2026-08-29)_
- When your change makes an existing test fail → run that suite on the untouched base first to attribute the failure. Because here it separated one real regression I caused from two failures that were already there, one of which my own fix resolved. _(2026-08-29)_
- When a module exposes a setting under a different name than the env var it reads → pin the mapping with a check, never infer it from the consumer. Because config.py does AUTH_USER = os.getenv("AGENTOS_USER"), so reading auth.py's config.AUTH_USER made AUTH_USER look like the env var; I 'fixed' passwd.py to print it and nearly shipped the exact lockout I was trying to prevent. _(2026-08-29)_
- When adding a write path to a hardened systemd service → widen ReadWritePaths in the same change. Because ProtectHome=read-only left /api/run/radar and /api/sync failing with 'Read-only file system' while the unit reported active and the equivalent scheduled timer kept working, so only the UI buttons broke and nothing looked wrong. _(2026-08-29)_
- When a layout places nodes for a canvas that has floating chrome over it → pass the layout the usable frame measured from the DOM, not the canvas box. Because a circle is right anywhere so the bug never showed in the ring view, and the first horizontal layout put its five best results behind the left rail. _(2026-08-29)_
- When forcing a label to always be drawn → give it space, never permission to overlap. Because bypassing collision rejection turned 12 search hits into one smear; a dropped label recovers on hover, an unreadable one never does. _(2026-08-29)_
- When adding a provider route to $DSH_HOME/settings.yaml → make sure its apiKeyEnv variable is actually set, or delete the route. Because pi-ai resolves every route's credential at startup and one missing variable aborts the whole harness with MISSING_CREDENTIAL rather than disabling that single route. _(2026-08-31)_
- When validating a DSH config change → start the unit; do not trust `dsh --dump-config`. Because dump-config resolves the cordis overlay only and never reads settings.yaml's provider block, so it exits 0 on a config that cannot boot. _(2026-08-31)_
- When an OpenAI-compatible endpoint returns 400 'Unknown name X: Cannot find field' → strip the field and retry, do not assume the model or key is wrong. Because Google's compat surface implements a SUBSET of OpenAI's schema and rejects the whole payload on one unknown field; pi-ai sends `store`, which broke every Gemini turn for weeks while looking like a model problem. _(2026-08-31)_
- When giving an agent a web tool → let it pass a query, not a URL, unless you have written a real address allowlist. Because a URL-taking fetch tool on EC2 reaches 169.254.169.254 for IAM credentials and 127.0.0.1 for your own services, and automations.research.readable has no scheme or private-address check. _(2026-08-31)_
- When a Gemini model 503s 'high demand' on AI Studio → try Vertex at locations/global before assuming the model is unusable. Because gemini-3.7-flash was unavailable on AI Studio for hours while answering 200 first try on Vertex, and availability is per-model per-location: us-central1 404'd on 3.7 but served 2.5-flash. _(2026-08-31)_
- When switching the gemini route to Vertex → rewrite every model id as <publisher>/<model> and match agent-default-model. Because Vertex rejects a bare id with 400 'Malformed publisher model', which reads like a missing model rather than a naming rule. _(2026-08-31)_
- When a credential arrives as an ordinary .json → check git check-ignore before saving it anywhere near the repo. Because .gitignore covered *.pem/*.key/*.env but not service-account .json, so the worst file in the system to leak was the one the rules missed; the same gap made server/.env.bak.<timestamp> publishable while server/.env was not. _(2026-08-31)_
- When verifying which model or route actually served a turn → check a side channel you control, not the agent's own answer. Because a headless run reported plausible correct results while the shim counter proved it never touched the intended backend; the DSH Models page had rewritten agent-default-model in settings.yaml underneath. _(2026-08-31)_
- When asked to make a streaming UI feel faster → look for a full re-render per chunk before touching anything else. Because AskView.paint() reparsed the entire markdown answer and rebuilt its innerHTML on every token, which is O(n^2) in answer length and gets worse exactly where the user is watching; one rAF coalesce fixed it without changing a pixel. _(2026-08-31)_
- When a fixed-position app looks off-centre or clipped on a phone → check for 100vh before anything else. Because a collapsing mobile URL bar makes 100vh TALLER than the visible viewport, and if a canvas sizes itself from that box the whole scene's centre shifts by half the difference. Use dvh, and pair viewport-fit=cover with env(safe-area-inset-*) or the notch eats your toolbar. _(2026-08-31)_
- When a request names a UI element that cannot be found → confirm it does not exist before deleting the nearest lookalike. Because 'delete the activities button' had no referent in this repo at all; the Activity nav in the reference screenshots belonged to a different product on screen, and the nearest matches here (Recency scrubber, Timeline layout) are both load-bearing. _(2026-08-31)_
- When asked to add a service to the t3.micro → measure free memory first and quote the number back. Because the box has 913 MB total with ~104 MB free while the three existing units already declare 1168 MB of caps, so anything agent-sized needs a resize decision from the user rather than an install. _(2026-08-31)_
