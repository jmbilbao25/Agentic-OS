# for it. The login form is application/x-www-form-urlencoded, which Starlette
# parses natively — declaring FastAPI Form() parameters instead would have pulled
# in python-multipart for no behavioural gain.

# Semantic search — optional but recommended.
# Without these the app runs keyword-only (SQLite FTS5 + BM25), which is a
# supported mode, not a broken one. fastembed pulls onnxruntime and ships
# quantised CPU weights; there is deliberately no torch here.
#
# sqlite-vec also needs a Python built with loadable SQLite extensions. Some
# distro and pyenv builds are not: check with
#   python -c "import sqlite3;print(hasattr(sqlite3.connect(':memory:'),'enable_load_extension'))"
# A False there is why an install with both packages present still reports
# keyword-only mode.
