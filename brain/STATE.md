# Working memory

Loaded on every boot. Hard ceiling ~60 lines — prune, don't append.

## Current focus
AgentOS is now **harness-agnostic**: kernel in `AGENTS.md`, portable config in
`config/`, per-vendor bindings generated by `adapters/install.sh`. Shipping a
visual second brain on an always-on server with hybrid search and a web UI.

## Active loops
- `deploy-always-on` — put the vault + UI on a `t3.micro`, reachable over TLS
- `harden-agentos` — prove each subsystem survives a real session boundary

## Vault layers
`brain/raw/` capture → `brain/wiki/` atomic knowledge → `brain/output/` artifacts.
Promote by rewriting, never by moving. Supporting: `STATE.md`, `lessons.md`,
`journal/` (append-only), `decisions/`, `loops/`.

## Environment facts
- Sandboxes are ephemeral; **git is the only durable layer**. Push or lose it.
- Never assume a harness supports hooks, cron, daemons, or global config —
  audit it. See [[Harness Capability Matrix]].
- A kernel is only as persistent as its delivery. See [[Binding Beats Building]].
- Model access is not transferable between vendors; keep the provider behind one
  env var. See [[Model Access Is Not Transferable]].

## The stack on the server — LIVE
- `https://jm-agentic-os-13-218-239-165.sslip.io` (bare-IP host still valid).
  EC2 `t3.micro` + 30 GB gp3, ~$10/mo. Reboot-tested; back in ~30s unattended.
- Retrieval: FTS5 + sqlite-vec fused with RRF, exact-name matches weighted apart.
  Index is disposable; markdown is truth. See [[Grep Beats Embeddings Here]].
- Embeddings on-box (BGE-small, CPU). Inference remote and OpenAI-compatible;
  model + fallback chain live-editable in the UI.
- Auth: one username + one PBKDF2 password hash, per-address lockout. Mint with
  `python -m server.passwd`. TLS: Caddy + Let's Encrypt on sslip.io — no domain,
  no DNS account, automatic. Tailscale Funnel is the `TLS=tailscale` alternative.
- Automations: `bin/os radar|research|distill|brief`, 6 keyless feeds, daily 06:15.
- Why a server at all: [[Local Runtime Closes The Gaps]].
