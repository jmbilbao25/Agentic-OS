The rings

      
ARMS layers, outermost first: Applications (output/,
      what you shipped), Routines (loops/), Memory
      (wiki/, raw/, journal/,
      decisions/), Skills (config/skills/). The
      core is AGENTS.md — the kernel every harness boots from.

      
Dot size is note length. Curves are [[wikilinks]]. Clicking a
      node dims everything more than one link away, so a dense graph stays
      readable. Click a ring name to hide that layer.

      
Automations

      
radar pulls six keyless feeds into brain/raw/.
      distil triages the newest capture into brain/output/.
      research gathers on one topic. Nothing writes to
      brain/wiki/ automatically — promotion to knowledge stays a
      deliberate act.
